Install

Up and running in minutes.

The VST3 plugin

  1. 1

    Close your DAW and run the installer.

  2. 2

    If Windows says “Windows protected your PC”

    Click More info then Run anyway

    The beta isn't code-signed yet.

  3. 3

    Allow the admin prompt.

    The last step downloads the AI engine. It's about 320 MB, needs internet and takes a few minutes.

  4. 4

    Rescan plugins.

    FL Studio
    Options > Manage plugins > Find installed plugins
    Ableton Live
    Settings > Plug-Ins > Rescan

    with “Use VST3 Plug-In System Folders” turned on.

  5. 5

    Add LISN StemSplitter to a track.

The desktop app

  1. 1

    Run LISN-Setup.exe.

    No admin prompt: it installs just for you. If Windows says “Windows protected your PC”, click More info, then Run anyway.

  2. 2

    Let it fetch the AI engine.

    About 320 MB. It needs internet and takes a few minutes.

  3. 3

    Open a song.

    Start menu > LISN or Right-click a song > Open with > LISN

FAQ

Good questions.

Is it free?+

Yes.

Does it upload my music?+

No. Everything runs on your PC.

Do I need a DAW?+

No. LISN, the desktop app, splits and plays songs on its own. The VST3 is for when you want the stems inside FL Studio or Ableton Live.

Does changing the tempo change the key?+

No. Tempo (0.5× to 2×, shown in BPM) and key (up to 12 semitones up or down) are separate. Double-click either box to reset it.

Is there a Mac version?+

Not yet.

Where are my stems saved?+

In %APPDATA%\StemSplitter\cache. You can drag them anywhere you like.

How do I uninstall?+

Go to Windows Settings > Apps, then LISN StemSplitter for the plugin or LISN for the desktop app. Each removes its own AI engine.

Why does Windows warn me?+

The beta isn't code-signed yet. Click More info, then Run anyway.
